Sharandev Fashions

LUCKY DRAW 

Build a modern, premium, mobile-first Lucky Draw web application for Sharandev Fashions. The primary goal is to collect customer contacts, increase WhatsApp engagement, and register visitors for a Lucky Draw with the simplest possible user experience.

UI Guidelines

Keep every screen clean and uncluttered.

Use:

Large fonts

Large buttons

Simple wording

High contrast

Maximum 1–2 actions per screen

Minimal typing

Big icons

Plenty of white space

Assume many visitors are not tech-savvy.

Animations

Include subtle premium animations:

Floating gift boxes

Sparkles

Confetti on success

Button hover effects

Smooth page transitions

Animated progress bar

Pulse effect on CTA buttons

Gold shimmer effect on headings

Avoid excessive animations that slow down the experience.

Overall Experience

The website should feel like participating in a premium festive Lucky Draw, not filling out a form.

The complete registration process should take less than 30 seconds, with an intuitive flow that even first-time smartphone users can complete comfortably.

The final result should resemble a premium event registration experience with elegant festive visuals, excellent mobile usability, and a polished, modern interface that encourages maximum participation.
